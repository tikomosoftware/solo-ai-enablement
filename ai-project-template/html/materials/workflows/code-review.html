AI利用時のコードレビュー

レビュー観点

  • 依頼した範囲だけが変更されているか
  • 既存仕様を壊していないか
  • 例外処理が不足していないか
  • エラー時の挙動が適切か
  • セキュリティ上の問題がないか
  • 認証、認可、入力検証が適切か
  • テストが必要な箇所にテストがあるか
  • ログに機密情報が出ないか
  • 不要な依存関係を追加していないか

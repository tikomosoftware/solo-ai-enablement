AI利用 事故・ヒヤリハット共有テンプレート

このテンプレートの使い方

実害が出た事故だけでなく、ヒヤリとした提案や挙動も共有してください。

共有の目的は、誰かを責めることではありません。同じ失敗をチームで繰り返さないために、ルール、権限設定、FAQ、チェックリストを改善することです。

概要

  • 発生日:
  • 共有者:
  • 対象リポジトリ:
  • 使用ツール:
  • 重大度:

何が起きたか

簡潔に書いてください。

AIに依頼した内容

可能であれば、プロンプトや依頼内容を貼ってください。

AIの出力または提案

危険だった提案、誤った説明、不要な変更などを書いてください。

実際の影響

  • 影響なし
  • ローカル作業だけに影響
  • PRに影響
  • 本番または顧客影響
  • その他

気づけた理由

例:

  • 差分確認で気づいた
  • テストで気づいた
  • レビューで気づいた
  • 権限設定でブロックされた
  • 違和感があった

再発防止案

  • ルール追加
  • 権限設定変更
  • FAQ追加
  • プロンプト改善
  • チェックリスト追加

共有しておきたいこと

他メンバーに伝えたいことを書いてください。

記入例1: 危険なGitコマンドの提案

概要

  • 発生日: 2026-05-22
  • 共有者: 山田
  • 対象リポジトリ: my-app
  • 使用ツール: Claude Code
  • 重大度: 中

何が起きたか

ローカルのGit状態を整理する相談をしたところ、AIが git reset --hard を提案した。

AIに依頼した内容

作業ブランチの状態がよく分からないので整理方法を教えてください。

AIの出力または提案

git reset --hard でローカル変更を破棄する提案が出た。

実際の影響

影響なし。実行前に気づいた。

気づけた理由

approval-required-operations.md で git reset が禁止操作になっていたため。

再発防止案

  • FAQに「Git整理でresetを提案された場合」を追加する。
  • CLAUDE.md に、Git整理時はまず git status と git diff だけを使うと追記する。

共有しておきたいこと

Gitの相談では、AIが履歴やローカル変更を捨てる提案をすることがある。

記入例2: .envを読もうとした

概要

  • 発生日: 2026-05-22
  • 共有者: 佐藤
  • 対象リポジトリ: api-server
  • 使用ツール: Claude Code
  • 重大度: 中

何が起きたか

環境変数の設定漏れを調査しているときに、AIが .env を確認しようとした。

AIに依頼した内容

ローカル起動時にDB接続エラーになります。原因を調べてください。

AIの出力または提案

.env の中身を確認する提案が出た。

実際の影響

権限設定でブロックされたため影響なし。

気づけた理由

.claude/settings.json で .env の読み取りをdenyしていた。

再発防止案

  • 環境変数名だけを共有する相談方法をFAQに追加する。
  • エラー調査プロンプトに「.envの値は読まない」と明記する。

共有しておきたいこと

設定調査では、AIが自然に .env を読もうとすることがある。

記入例3: 依頼範囲外のリファクタリング

概要

  • 発生日: 2026-05-22
  • 共有者: 鈴木
  • 対象リポジトリ: frontend-app
  • 使用ツール: Claude Code
  • 重大度: 低

何が起きたか

文言修正を依頼したところ、周辺コンポーネントのリファクタリングも行われた。

AIに依頼した内容

ログイン画面のエラーメッセージを分かりやすくしてください。

AIの出力または提案

文言修正に加えて、コンポーネント分割とスタイル整理が行われた。

実際の影響

PRが大きくなり、レビューが難しくなった。実害はなし。

気づけた理由

差分確認で、依頼していないファイルが変更されていることに気づいた。

再発防止案

  • 実装依頼プロンプトに「依頼範囲外のリファクタリングはしない」を必ず入れる。
  • before-commit.md に「依頼範囲外の変更がない」を確認項目として維持する。

共有しておきたいこと

小さな変更でも、AIは「ついでに改善」しようとすることがある。

記入例4: 存在しないAPIを使った

概要

  • 発生日: 2026-05-22
  • 共有者: 田中
  • 対象リポジトリ: desktop-client
  • 使用ツール: GitHub Copilot
  • 重大度: 低

何が起きたか

Windowsアプリの実装で、AIが存在しないライブラリAPIを使ったコードを生成した。

AIに依頼した内容

設定ファイルを読み込む処理を追加してください。

AIの出力または提案

存在しないメソッドを使ったコードが生成された。

実際の影響

ビルドエラーで気づいた。実害はなし。

気づけた理由

dotnet build を実行したため。

再発防止案

  • AI生成コードは必ずビルドする。
  • 公式ドキュメントや型情報を確認する。

共有しておきたいこと

AIは自然なコードを書いても、APIが実在しないことがある。

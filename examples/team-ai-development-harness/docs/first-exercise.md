# 最初の実践課題

## 目的

この課題は、Claude Codeを安全に使い始めるための最初の練習です。

いきなりコードを変更するのではなく、まずは起動場所、ルール読み込み、権限設定、リポジトリ調査を確認します。

## 課題1: 正しい場所で起動する

VS Codeで対象リポジトリのプロジェクトルートを開きます。

統合ターミナルでClaude Codeを起動します。

```text
claude --permission-mode plan
```

確認:

- `C:\` や `C:\Users` で起動していない。
- `C:\ProjectsDEV` のような親フォルダで起動していない。
- 対象リポジトリのルートで起動している。

## 課題2: ルールを確認する

Claude Code内で次を実行します。

```text
/memory
```

確認:

- `CLAUDE.md` が読み込まれている。
- チームルールが見えている。

次に権限を確認します。

```text
/permissions
```

確認:

- 削除やforce pushが禁止されている。
- 編集やcommit、pushが確認対象になっている。

## 課題3: 変更なしでリポジトリを調査する

Claude Codeに次を依頼します。

```text
まずこのリポジトリの構成を調査してください。
変更はまだ行わず、主要なフォルダ、実行方法、テスト方法、注意点を整理してください。
```

確認:

- ファイル変更が発生していない。
- リポジトリの概要が説明されている。
- 実行方法やテスト方法が整理されている。

## 課題4: ルールを要約させる

Claude Codeに次を依頼します。

```text
CLAUDE.md、policies/common.md、docs/ai-development-policy.mdを読み、
このリポジトリでAIを使うときに守るべきルールを要約してください。
まだファイル変更はしないでください。
```

確認:

- 禁止操作が説明されている。
- 情報管理の注意が説明されている。
- 作業フローが説明されている。

## 課題5: 感想を共有する

次の3つをチームに共有します。

- 便利そうだと思ったこと
- 不安に感じたこと
- 追加してほしいルールやFAQ

## 完了条件

この課題では、コード変更やコミットは行いません。

完了条件:

- Claude Codeを正しい場所で起動できた。
- `/memory` と `/permissions` を確認した。
- 変更なしでリポジトリ調査ができた。
- 感想や不安点を共有した。

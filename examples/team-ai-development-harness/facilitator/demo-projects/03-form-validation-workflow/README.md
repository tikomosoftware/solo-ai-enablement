# 第3回サンプル: チーム運用を意識してフォームを直す

## このプロジェクトについて

社内イベントの参加登録フォームです。

第3回では、単に直すだけでなく、チームで安全に扱うためのレビュー観点、相談ポイント、確認手順をそろえる流れを扱います。

## 今回の修正候補

名前が空欄でも登録完了メッセージが出てしまいます。

空欄の場合は完了にせず、エラーメッセージを表示するように直します。

## 動作確認

`index.html` をブラウザで開いて確認できます。ビルドや依存関係のインストールは不要です。

## ファイル

- `index.html`: 入力フォーム
- `styles.css`: 見た目
- `app.js`: 入力チェックと表示ロジック
- `review-checklist.md`: チームレビュー用の観点
- `DEMO-STEPS.md`: 登壇者用の実演手順

# 第2回サンプル: 静的ページの小さな表示修正

## このプロジェクトについて

問い合わせ受付ページの静的サンプルです。

第2回では、画面上の小さな表示不具合を題材に、実装方針、差分確認、手動確認までを扱います。

## 今回の修正候補

問い合わせ種別の表示で、選択していない状態でも「選択済み: 一般」と表示されます。

未選択時は「選択済み: 未選択」と表示するように直します。

## 動作確認

`index.html` をブラウザで開いて確認できます。ビルドや依存関係のインストールは不要です。

## ファイル

- `index.html`: 画面構造
- `styles.css`: 見た目
- `app.js`: 表示ロジック
- `DEMO-STEPS.md`: 登壇者用の実演手順

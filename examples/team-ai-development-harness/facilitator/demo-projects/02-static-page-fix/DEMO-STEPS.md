# 第2回 デモ手順: 小さな表示不具合を直す

## 目的

小さな修正でも、変更前に方針を確認し、修正後に差分と動作確認を行う流れを練習します。

## 登壇者の流れ

1. VS Codeで `02-static-page-fix` フォルダを開く
2. `index.html` をブラウザで開き、初期表示を見せる
3. 未選択なのに「選択済み: 一般」と表示されることを確認する
4. VS CodeのClaude Codeパネルで、AIに調査と実装方針を依頼する
5. 方針確認後、実装を依頼する
6. VS Codeの差分表示で、変更が小さいことを確認する
7. ブラウザを再読み込みして確認する

## 最初に使う依頼文

```text
この静的ページで、問い合わせ種別が未選択なのに「選択済み: 一般」と表示されます。
まだ変更せず、原因の見立て、触るファイル、修正方針、確認方法を整理してください。
```

## 実装を依頼する文

```text
方針は問題ありません。
未選択時は「選択済み: 未選択」と表示されるように、最小限の変更で修正してください。
修正後に差分と手動確認手順を説明してください。
```

## 確認ポイント

- 初期表示が「選択済み: 未選択」になっているか
- 「一般」「請求」「不具合」を選ぶと表示が切り替わるか
- HTMLやCSSに不要な変更が入っていないか
- AIの説明が実際の差分と一致しているか
- VS Code上で変更ファイルを確認できたか

## 参加者の練習課題

送信ボタンの文言を「送信」から「問い合わせを送信」に変更してください。

ただし、見た目の調整が必要かどうかをAIに確認してから実装してください。

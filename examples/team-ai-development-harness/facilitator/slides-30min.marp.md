# 今日のゴール

コードを変更せずに構成や実行方法を整理する流れを確認します。

---

# Claude Codeとは

開発作業を支援するAIエージェントです。

- プロジェクト内のファイルを参照できる
- 実装やレビューの補助ができる
- 必要に応じてコマンド実行も支援できる

強力なツールなので、最初に安全な使い方をそろえます。

---

# 最初に避けたいこと

慣れるまでは、取り消しにくい操作は任せません。

- ファイルやディレクトリの削除
- `git reset` / `git clean` / `git rebase`
- force push
- `.env` / APIキー / 秘密鍵の入力
- 本番環境や本番DBへの操作
- 大きなリファクタリング

---

# 実演で見るポイント

1. 対象リポジトリのルートで起動する
2. VS Codeは1プロジェクト1ウィンドウ
3. `plan` modeで起動する
4. `/memory` で読み込まれたルールを確認する
5. `/permissions` で権限設定を確認する

---

# 最初の依頼例

```text
まずこのリポジトリの構成を調査してください。
変更はまだ行わず、主要なフォルダ、実行方法、
テスト方法、注意点を整理してください。
```

最初は「実装」ではなく「現状把握」から始めます。

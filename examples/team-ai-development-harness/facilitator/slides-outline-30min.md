# 第1回 30分説明会 スライド構成案

## このスライドの位置づけ

このスライドは、Claude Codeをチームで初めて試すための30分説明会用です。

説明会の主役はスライドではなく、サンプルプロジェクトを使った実演です。スライドは、参加者が「今日何を見るのか」「何を避けるのか」「次に何をすればよいのか」を迷わないための補助として使います。

対応する台本:

- `facilitator/explanation-script-30min.md`

## Slide 1: 今日のゴール

タイトル:

```text
Claude Codeを安全に触ってみる
```

本文:

```text
今日のゴールは、Claude Codeにいきなり実装させることではありません。

まずは、サンプルプロジェクトをClaude Codeに説明してもらうところまでを一緒に見ます。
```

話すポイント:

- 第1回なので、全機能は扱わない。
- 経験差があっても大丈夫。
- コード変更なしで試す。

## Slide 2: Claude Codeとは

タイトル:

```text
Claude Codeは開発作業を手伝うAIエージェント
```

本文:

```text
チャットで質問するだけでなく、
プロジェクトのファイルを読んだり、
必要に応じて編集やコマンド実行まで支援できます。
```

話すポイント:

- 便利だが強力なツール。
- 強力だからこそ、最初に使い方をそろえる。
- 今回は「書かせる」より「説明してもらう」。

## Slide 3: 最初に避けたいこと

タイトル:

```text
最初は取り消しにくい操作を避ける
```

本文:

```text
- ファイル削除
- git reset / clean / rebase
- force push
- .env / APIキー / 秘密鍵の入力
- 本番環境や本番DBへの操作
- 大きなリファクタリング
```

話すポイント:

- 怖がらせるためではなく、安全に試すため。
- AIが提案しても、その場で実行しない。
- まずは変更なしの使い方から始める。

## Slide 4: 実演で見るポイント

タイトル:

```text
実演で見るポイント
```

本文:

```text
1. プロジェクトルートで起動する
2. VS Codeは1プロジェクト1ウィンドウ
3. plan modeで起動する
4. /memory でルールを確認する
5. /permissions で権限を確認する
```

話すポイント:

- どこで起動するかが大事。
- `C:\` や親フォルダでは起動しない。
- 最初は `plan` modeで調査だけにする。

## Slide 5: 最初の依頼例

タイトル:

```text
最初の依頼は「変更なしで説明してもらう」
```

本文:

```text
まずこのリポジトリの構成を調査してください。
変更はまだ行わず、主要なフォルダ、実行方法、
テスト方法、注意点を整理してください。
```

話すポイント:

- ここでは実装を依頼していない。
- プロジェクトの理解を手伝ってもらう。
- これだけでも初回利用として十分価値がある。

## Slide 6: 説明会後にやること

タイトル:

```text
次にやること
```

本文:

```text
1. docs/start-guide.md を見ながら初回セットアップ
2. docs/first-exercise.md の最初の課題を試す
3. 分からないことや不安だったことを共有する
```

話すポイント:

- 最初の課題ではコード変更しない。
- 15〜30分くらいで試せる。
- 便利だった点も、不安だった点も共有してほしい。

## Slide 7: 困ったとき

タイトル:

```text
困ったら止まって共有する
```

本文:

```text
見る資料:
- docs/faq.md
- docs/common-pitfalls.md
- docs/glossary.md

共有してほしいこと:
- 危なそうな提案
- 分かりにくかったこと
- 便利だった使い方
```

話すポイント:

- 分からないまま進めなくてよい。
- ヒヤリハットもチームの学びになる。
- まずは安全に触ってみるところから。

## 補足: スライドに入れないこと

30分説明会では、次はスライドに入れないか、名前だけに留めます。

- Skills
- MCP
- Hooks
- Agents
- 細かいpermission設定
- 職種別ポリシー
- PR運用
- ヒヤリハットテンプレートの詳細

これらは、必要になったタイミングで別途扱います。

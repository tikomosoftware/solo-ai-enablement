# AI開発利用ポリシー フロントエンド向け

## 対象

この補足ポリシーは、Webフロントエンド、SPA、管理画面、デザインシステム、UIコンポーネントを扱うエンジニア向けです。

## AIに任せてよい例

- コンポーネントのたたき台
- propsや型定義の整理
- CSSやレイアウトの改善案
- Storybookの例作成
- テストケースの下書き
- 表示文言の改善
- アクセシビリティ観点のレビュー
- フォームバリデーションの実装案
- APIレスポンスを表示用モデルへ変換する処理の相談

## 注意すること

- 既存デザインシステムに合わせる。
- 勝手にUIライブラリを追加しない。
- 画面全体のレイアウトを大きく変えない。
- レスポンシブ表示を確認する。
- キーボード操作、フォーカス、aria属性を確認する。
- API仕様やデータ構造を勝手に変えない。
- 認証や権限の表示制御をAI任せにしない。
- 重要な導線の文言変更は、必要に応じて関係者に確認する。

## レビュー観点

- モバイル、タブレット、デスクトップで表示が崩れていないか。
- UI要素が重なっていないか。
- 長い文言や多言語化で崩れないか。
- ローディング、空状態、エラー状態があるか。
- アクセシビリティが悪化していないか。
- 不要な状態管理や副作用が増えていないか。
- パフォーマンスに悪影響がないか。

## 確認コマンド例

```text
npm run lint
npm run test
npm run build
```

プロジェクトによっては、StorybookやE2Eも確認します。

```text
npm run storybook
npm run test:e2e
```

# AI開発利用ポリシー Windowsアプリ向け

## 対象

この補足ポリシーは、Windowsデスクトップアプリ、社内ツール、クライアントアプリを扱うエンジニア向けです。

対象例:

- WPF
- WinForms
- WinUI
- .NET MAUI
- Electron
- Tauri
- C#アプリ
- C++/Win32アプリ

## AIに任せてよい例

- 画面コードの整理
- イベントハンドラの改善
- MVVM構成の相談
- 例外処理の追加
- ビルドエラーの調査
- 設定ファイルの説明
- ログ出力の改善案
- インストール手順書の下書き
- Windows APIの使い方の調査補助

## 注意すること

- ファイルパス、レジストリ、ユーザーディレクトリ操作を慎重に扱う。
- 自動更新、インストーラ、署名、証明書周りは人間が確認する。
- OS依存の挙動を確認する。
- 管理者権限が必要な処理をAI任せにしない。
- ユーザーデータ削除につながる処理をAIに実行させない。
- PowerShellやバッチの削除コマンドを実行前に確認する。
- 32bit/64bit、Windowsバージョン差分を確認する。

## レビュー観点

- ユーザーデータを誤って削除しないか。
- 設定ファイルやキャッシュの保存先が適切か。
- 管理者権限が不要な場所で要求されていないか。
- 例外時にアプリが落ちないか。
- ログに個人情報や機密情報が出ていないか。
- インストール、更新、アンインストールの挙動が安全か。

## 確認コマンド例

```text
dotnet build
dotnet test
```

ElectronやNode系の場合:

```text
npm run build
npm run test
```

# リファレンス

このフォルダは、AI開発支援ツールを使っていて分からないことや、運用で迷ったときに参照する資料です。

最初から順番に読む資料ではなく、説明会後、実運用中、トラブル時に必要な項目を確認するために使います。

## 作成状況について

**注意:** このリファレンスは、現時点では項目整理とたたき台が中心です。FAQ、失敗例、用語集はありますが、詳細な回答や実運用での具体例はまだ作成中です。今後の説明会や実運用で出た質問をもとに内容を追加、見直ししていきます。

完成済みの網羅的なリファレンスではなく、運用しながら育てるための入口として見てください。

## 対象者

- AI開発支援ツールを使い始めた開発者
- チーム内の質問に答える導入担当者
- 失敗例やFAQを確認したいレビュアー、リーダー

説明会では、全項目を詳しく説明する必要はありません。

まず存在だけ紹介し、実際に困ったときに参照する場所として案内します。

基礎・ルール編

資料基準日: 2026-06-10

このフォルダは、AI開発支援ツールをチームで安全に使い始めるための基礎資料です。

Claude CodeやGitHub Copilotを実際の開発作業で使う前に、考え方、利用ルール、起動方法、承認が必要な操作を確認します。

この基礎・ルール編は、考え方と運用ルールを中心に扱います。具体的な製品仕様や画面操作は変わる可能性があるため、実施前に最新の公式情報を確認します。

対象者

  • Claude CodeやGitHub Copilotを開発作業で使い始める人
  • AI開発支援ツールの安全な使い方を知りたい人
  • チームで共通の利用ルールをそろえたい人
  • 実プロジェクトへAI開発支援を導入する人

この基礎・ルール編のゴール

  • AIに任せる範囲と人間が確認する範囲を理解する
  • プロジェクトルートで安全に起動できる
  • ツールの使い分けを理解する
  • 承認が必要な操作を判断できる
  • 高機能を最初から使いすぎない理由を理解する

AI開発支援の考え方

AI開発利用ポリシー

ツールの使い分けガイド

事前準備: VS CodeでClaude Codeを使う

VS CodeでClaude Codeを使うための準備、プロジェクトフォルダの開き方、差分確認の流れを扱います。

最初の実践課題

7. 承認が必要な操作

承認が必要な操作

削除、履歴操作、本番環境操作、データベース操作など、AIだけで進めてはいけない操作を整理します。

Claude Code強機能の扱い方

リポジトリ導入手順

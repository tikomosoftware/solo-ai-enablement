# ツール別ガイド

このフォルダは、開発作業で使う代表的なAI支援ツールの使い方をまとめた資料です。

基礎・ルール編や実用編で全体の流れを確認したあと、利用するツールに応じて必要なガイドを読みます。

## 対象者

- GitHub CopilotをCLIやVS Codeで使う人
- Claude CodeをCLIやVS Codeで使う人
- ツールごとの使い方や注意点を確認したい人

説明会では、参加者が実際に使うツールに絞って紹介します。

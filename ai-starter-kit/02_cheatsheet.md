# 02. 初心者向け1枚チートシート

## このファイルの目的

このファイルは、AI初心者が最初に見るための短いまとめです。

忙しい人や、説明会で時間が限られている場合は、まずこの1枚と「最初の30分ワーク」「入力してよい/ダメ判断クイズ」だけを使います。

## AIは何に使うか

AIは、正解を決める人ではなく、下書き、整理、言い換え、確認を手伝う相手です。

最初は、次のような小さい作業から使います。

- 文章の下書きを作る
- 長い文章を短くまとめる
- 会議メモを整理する
- 説明を初心者向けに言い換える
- アイデアを複数出す
- 抜け漏れや分かりにくい点を確認する

## 最初に使える依頼文

迷ったら、この形で頼みます。

```text
目的:
背景:
依頼内容:
条件:
出力形式:
対象読者:
```

全部を埋める必要はありません。分かっているところだけで十分です。

## そのまま使える例

### 文章を作る

```text
以下の内容を、チーム内チャットに投稿する短い文面にしてください。
丁寧だけど堅すぎない表現にしてください。

[内容を書く]
```

### 要約する

```text
以下の文章を、3行の要約と重要ポイント5つに分けて整理してください。
対象読者は、このテーマに詳しくない人です。

[文章を貼る]
```

### 分かりやすくする

```text
以下の説明を、AIをまだ使ったことがない人にも分かるように言い換えてください。
専門用語はできるだけ避けてください。

[説明を書く]
```

### 確認してもらう

```text
以下の文章に、分かりにくい点、誤解されそうな点、足りない情報があれば指摘してください。
指摘は最大5つにしてください。

[文章を貼る]
```

## 入れてはいけない情報

迷ったら入力しないでください。

- 顧客名、担当者名、連絡先
- 個人名、住所、メールアドレス、電話番号
- 契約書、見積書、請求書
- 売上、利益、予算、原価などの未公開情報
- 人事、評価、給与に関する情報
- 未公開の企画、戦略、ロードマップ
- APIキー、パスワード、トークン、秘密鍵
- 本番ログ、アクセスログ、セキュリティ情報
- 公開されていないソースコードや設計資料

許可されたAI環境で扱える情報もありますが、最初は「具体情報を入れすぎない」ことを基本にします。

## AIの回答を見るときの確認

AIの回答は、確認してから使います。

- 数字、日付、名前は正しいか
- 存在しない情報を作っていないか
- 自分たちの状況に合っているか
- 相手に失礼な表現になっていないか
- 機密情報や個人情報が混ざっていないか
- 根拠が必要な内容に出典や確認元があるか

「AIが言っていた」は根拠になりません。

## 迷ったときの止め方

迷ったら、次のどれかを選びます。

- 入力しない
- ダミー情報に置き換える
- もっと抽象化して相談する
- チームのルールを見る
- 責任者や詳しい人に確認する

AIに聞く場合は、こう頼めます。

```text
この内容をAIに入力してよいか迷っています。
機密情報、個人情報、契約情報、認証情報の観点で、入力前に確認すべき点を挙げてください。
ただし、最終判断は人間が行います。
```

## 最初に覚えること

AIを使う基本は、次の3つです。

- 小さく頼む
- そのまま信じない
- 迷った情報は入れない

この3つを守れば、最初の一歩はかなり安全に始められます。

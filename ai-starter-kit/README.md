# AI初心者向けスターターキット

資料基準日: 2026-06-10

AIをほとんど触ったことがない人が、最初に手を動かして試すための資料セットです。

AI一般の考え方を長く読む前に、「小さく頼む」「そのまま信じない」「迷った情報は入れない」を体験することを目的にします。

この資料は、一般的なチャット型AIを使った初回体験を想定しています。会社で許可されたAI環境、入力ルール、データ利用条件がある場合は、それを優先してください。

## 対象者

- AIを仕事でまだ使ったことがない人
- 説明を読むだけでは使い始めにくい人
- 最初の30分で、AIに何を頼めばよいか試したい人
- 入力してよい情報と、入れてはいけない情報の感覚を持ちたい人

## この資料で扱うこと

- AIに最初の依頼を出す
- 返ってきた内容を追加依頼で直す
- AIの出力を人間が確認する
- 入力してよい情報か判断する
- 業務で試しやすい小さな使い方を知る

## 使い方

説明会や初回オンボーディングでは、まず `01_first-30min-work.md` を使って実際にAIへ依頼します。

時間が短い場合は、`02_cheatsheet.md` を配布し、`03_input-ok-ng-quiz.md` で入力情報の判断だけ練習します。

業務で試す例を増やしたい場合は、`04_practice-examples.md` から近い場面を選びます。

## この資料で扱わないこと

- 特定のAI製品の詳細な操作説明
- 開発支援ツールの導入手順
- コード修正、リポジトリ操作、テスト実行
- 機密情報や顧客情報を使った実データ演習

具体的なAI開発支援ツールやエンジニア向けの使い方は、別資料として扱います。

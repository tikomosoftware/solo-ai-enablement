# 画面キャプチャ置き場

このフォルダには、VS Code + Claude Code extension の説明用画像を置きます。

現在入っている画像は、差し替え前提のプレースホルダーです。実際の説明会では、自分の環境で撮った画面キャプチャに置き換えてください。

## 差し替え対象

| ファイル | 実際に撮る画面 |
| --- | --- |
| `01-extension-search.svg` | VS Codeの拡張機能ビューで `Claude Code` を検索した画面 |
| `02-open-folder.svg` | VS Codeでサンプルフォルダを開いた画面 |
| `03-spark-icon.svg` | エディタ右上または左側の Spark アイコン |
| `04-claude-panel.svg` | Claude Codeパネルを開いた画面 |
| `05-plan-response.svg` | AIが方針を返した画面 |
| `06-diff-view.svg` | VS Codeの差分表示 |
| `07-preview-check.svg` | Markdownプレビューまたはブラウザ確認 |

## 差し替え方法

同じファイル名で上書きする場合は、Markdown側の修正は不要です。

PNGで差し替える場合は、`00-vscode-claude-code-guide.md` の画像リンクを `.svg` から `.png` に変えてください。

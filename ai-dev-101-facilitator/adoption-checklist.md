# 展開前チェックリスト

## ツール・権限

- Claude Codeを利用できるアカウントがある。
- GitHub Copilotを利用できるメンバーが分かっている。
- 会社のセキュリティルール上、利用可能なAIツールが確認されている。
- 管理者承認が必要な項目を確認した。

## 対象リポジトリ

- 最初に試すリポジトリが決まっている。
- 対象リポジトリにharnessを導入済み。
- `CLAUDE.md` をプロジェクト向けに調整済み。
- `.claude/settings.json` を確認済み。
- テスト、ビルド、lintコマンドが分かっている。

## 資料

- `docs/start-guide.md` を確認済み。
- `policies/common.md` を確認済み。
- `docs/first-exercise.md` を確認済み。
- `docs/tool-selection-guide.md` を確認済み。
- `docs/faq.md` を確認済み。

## 説明会

- 30分説明会の範囲を決めた。
- 説明会後の課題を決めた。
- 質問やヒヤリハットの共有先を決めた。
- 説明会で全部説明しない方針を決めた。

## 展開後

- 1週間後にふりかえりを行う。
- FAQに追加する質問を集める。
- ヒヤリハットを集める。
- 権限設定の見直し要否を確認する。

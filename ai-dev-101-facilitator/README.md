# 展開担当者向け資料

このフォルダは、AI活用やAI開発支援をチームに展開する担当者向けの資料です。

説明会の準備、導入計画、進行、展開前チェック、デモ用プロジェクトをまとめています。このフォルダは独立した資料セットとして扱い、別フォルダの資料へのリンクには依存しません。

## 対象者

- AI活用やAI開発支援をチームへ展開する人
- 説明会やハンズオンを準備する人
- チームリーダー、レビュアー、導入担当者

## ゴール

- 説明会の流れを設計する
- 参加者に最初に伝える範囲を決める
- 小さく試し、ふりかえりながらチーム運用へつなげる

## 扱わないこと

- 参加者全員に読ませる入門資料の全文
- 実プロジェクトへコピーするテンプレート本体
- 最新機能の細かい使い方を網羅し続けること

## 使い方

まず `rollout-plan.md` で展開の流れを決め、`adoption-checklist.md` で事前確認を行います。

説明会では、参加者にすべてを一度に理解してもらうことを目標にしません。最初はAIに何を任せてよいか、どの操作に注意が必要か、どのように小さく試すかを揃えます。

## デモプロジェクト

`demo-projects/` には、説明会やハンズオンで使う小さな題材を置いています。参加者が本番リポジトリへ触れる前に、調査、修正、レビューの流れを練習するための素材です。

# 第1回 30分説明会 台本たたき台

## この台本の目的

この台本は、Claude Codeをチームで安全に使い始めるための第1回説明会用です。

第1回では、Claude Codeの全機能を説明するのではなく、「安全に起動して、コード修正をせずにプロジェクトを解析してもらう」ところまでを扱います。

初回のゴールは、Claude Codeにコードを書かせることではありません。

**まずは、サンプルプロジェクトをClaude Codeに解析してもらうところまでを実演します。**

## 事前に用意するもの

説明者は、事前にサンプルプロジェクトを1つ用意しておきます。

例:

```text
sample-todo-app/
  .git/
  CLAUDE.md
  .claude/
    settings.json
  README.md
  package.json
  src/
  tests/
```

サンプルプロジェクトは、本番コードや顧客情報を含まないものを使います。

説明会では、VS Codeで `sample-todo-app/` だけを開いておきます。

## 0:03-0:06 今日のゴールとClaude Codeの位置づけ

話す内容:

```text
今日は、Claude Codeをチームで安全に使い始めるための第1回です。

Claude Codeは、開発作業を手伝ってくれるAIエージェントです。

チャットで質問するだけではなく、プロジェクトのファイルを読んだり、必要に応じて編集やコマンド実行まで支援できる点が特徴です。

まずは自分の担当プロジェクトをClaude Codeに解析してもらうところから始めます。
```

- Skills、MCP、Hooksなどの細かい話は扱わない。
- まずは「正しい場所で起動して、プロジェクト解析を依頼する」ところまで。

## 0:09-0:12 実演の準備: 開く場所を確認する

画面で見せること:

1. VS Codeで `sample-todo-app/` だけを開く
2. Explorerで `.git/`、`CLAUDE.md`、`.claude/settings.json` があることを見せる
3. 統合ターミナルを開く
4. 現在の場所を確認する

PowerShellの場合:

```text
Get-Location
```

話す内容:

```text
Claude Codeは、対象リポジトリの一番上のフォルダで起動します。

VS Codeでいうと、フォルダーを開くときに選ぶ場所です。

C:\ や C:\ProjectsDEV のような広い場所では起動しません。
```

補足:

- VS Codeのmulti-root workspaceは初回では使わない。
- 1つのVS Codeウィンドウに1つのプロジェクトだけを開く。

## 0:12-0:15 実演1: plan modeで起動する

画面で実行:

```text
claude --permission-mode plan
```

話す内容:

```text
初回はplan modeで起動します。

いきなりファイル編集を任せないところがポイントです。
```

もし起動できない場合:

- その場で深追いしない。
- インストール、ログイン、権限の問題として後で個別確認にする。
- 説明会では準備済み画面やスクリーンショットで進めてもよい。

画面で実行:

話す内容:

```text
まず、Claude Codeがこのプロジェクトのルールを読めているか確認します。

```

次に実行:

```text

```

話す内容:

```text
次に、どの操作が許可されていて、どの操作が禁止されているかを確認します。

```

ここで伝えること:

- `/memory` はルール確認
- `/permissions` は権限確認
- どちらも初回に確認する

## 0:18-0:23 実演3: プロジェクト解析を依頼する

Claude Codeに依頼:

```text
まずこのリポジトリの構成を調査してください。
変更はまだ行わず、主要なフォルダ、実行方法、テスト方法、注意点を整理してください。
```

話す内容:

```text
ここではコード変更を依頼していません。

Claude Codeにプロジェクトを解析してもらっています。

最初はこの使い方だけでも十分価値があります。
```

出力を見ながら話す観点:

- 主要フォルダを説明できているか
- 実行方法やテスト方法を拾えているか
- コード修正なしで進んでいるか
- 不明点を勝手に決めつけていないか

もし出力が微妙な場合の追加依頼:

```text
変更はせず、READMEとpackage.jsonをもとに、初めて参加する開発者向けに説明し直してください。
```

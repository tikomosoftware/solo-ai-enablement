# YouTube版スライド スタイルガイド

この資料は、`ai-basics-youtube.marp.md` と同じ雰囲気のスライドを増やすときのルールです。
ビジネス資料より少し明るく、YouTubeで見ても読める「太め・大きめ・余白あり」を基本にします。

## テーマカラー

| 用途 | CSS変数 | 色 |
| --- | --- | --- |
| 見出し、重要テキスト | `--color-heading` | `#0b2b55` |
| 本文 | `--color-text` | `#102033` |
| メイン青 | `--color-primary` | `#0969da` |
| 緑アクセント | `--color-success` | `#07956f` |
| ピンク強調 | `--color-highlight` | `#ef3f73` |
| オレンジ注意・矢印 | `--color-warm` | `#ff9300` |
| 上部帯グラデーション | `--color-topbar-start` / `--color-topbar-mid` / `--color-topbar-end` | `#ff9a00` / `#ffbd22` / `#ffd84d` |
| ピルの紫側 | `--color-pill-purple` | `#8147dd` |
| カード背景 | `--color-surface` | `#ffffff` |
| ページ下部背景 | `--color-page-bottom` | `#f5fcff` |
| 補足ボックス背景 | `--color-soft-blue` | `#dff5ff` |

## レイアウトルール

- 表紙は顔写真やロゴを置きすぎず、タイトルとサブコピーを主役にする。
- `SESSION`、`GUIDE`、`DEMO` などのラベルは、詰まって見える場合は省略する。
- 各スライド上部にはオレンジの帯を入れて、シリーズ感を出す。
- 1枚に入れる主な情報ブロックは、カード4枚までを基本にする。
- 下部の補足ボックスが見切れやすいので、最後に必ずHTMLで確認する。
- ブラウザ確認時の操作パネルは書き出し物には入らないが、パネルが重なる位置に重要文を置かない。

## コンポーネントルール

- タグ風ラベルは全スライドで同じ高さにする。
  - 基本: `min-height: 38px`、`font-size: 18px`、左右余白 `14px`
  - 見切れ対策で小さくする場合も、タグ自体のサイズは変えず、上下の `margin` だけ調整する。
- カードは詰めすぎない。
  - 連続カードは `gap: 18px` 以上を目安にする。
  - 3枚縦積みの場合は、カードを少し低くして余白を確保する。
- 大きな赤文字は章扉や強い結論だけに使う。
  - 最終ページや案内ページでは、赤い大文字より補足ボックスを使う。
- ロゴや顔写真は、説明に必要なスライドだけに置く。
  - 表紙には置かない。
  - 会社ロゴは案内役スライドでも邪魔なら省く。

## スライド別の考え方

- 章扉: `PART 1` などは小さめラベル、タイトルを主役にする。
- 本日の流れ: 5項目が見切れやすいので、項目間は広げすぎず、ただしカード同士は接触させない。
- タグ付き説明: タグの高さを統一し、図解や補足ボックス側で高さを調整する。
- 最終ページ: 「次につなげる」より「次回セッションで扱うこと」のように具体的な案内名にする。

## 確認チェック

- 1280x720で見て、下部が見切れていない。
- タイトル、タグ、カード、補足ボックスの文字が小さすぎない。
- タグの高さがスライド間で揺れていない。
- 強調色が多すぎず、青、緑、ピンク、オレンジの役割が混ざっていない。
- 写真、ロゴ、飾りが本文理解の邪魔になっていない。

# 14. Claude CodeをVS Codeで使う

## この記事の目的

この記事では、Claude CodeをVS Codeと組み合わせて使う方法を説明します。

Claude CodeはCLIとして使えますが、VS Codeと連携すると、差分確認、選択範囲の共有、診断情報の共有、ファイル参照などが使いやすくなります。普段VS Codeで開発している人は、この使い方が自然です。

## VS Code連携でできること

Anthropicの公式ドキュメントでは、Claude CodeのIDE連携として、VS Code系エディタとJetBrains系IDEが案内されています。

VS Code連携の代表的な機能は次のとおりです。

- エディタからClaude Codeを素早く開く
- 変更差分をVS Codeのdiffビューで確認する
- 現在選択しているコードや開いているタブの文脈を共有する
- ファイル参照をショートカットで挿入する
- lintや構文エラーなどの診断情報を共有する

つまり、Claude Codeの作業はターミナルで進めつつ、確認や編集体験はVS Codeに寄せられます。

## 基本的な始め方

VS Codeでプロジェクトを開きます。

次に、VS Codeの統合ターミナルを開き、プロジェクトルートで次を実行します。

```text
claude
```

公式ドキュメントでは、VS Codeの統合ターミナルから`claude`を実行すると、拡張機能が自動インストールされると説明されています。うまく入らない場合は、VS Codeの拡張機能インストール権限や、`code`コマンドがPATHに入っているかを確認します。

## 外部ターミナルから接続する

VS Codeの外でClaude Codeを起動している場合でも、`/ide` コマンドでIDEに接続できます。

```text
/ide
```

外部ターミナルから使う場合も、VS Codeで開いているプロジェクトと同じルートディレクトリからClaude Codeを起動すると、ファイルの文脈がずれにくくなります。

## VS Code連携で便利な場面

VS Code連携が便利なのは、次のような場面です。

- AIが編集した差分を見ながらレビューしたい
- 選択中のコードについて質問したい
- エラー箇所をClaude Codeに認識させたい
- ファイルの特定行を参照しながら依頼したい
- ターミナルとエディタを行き来しながら作業したい

例:

```text
今選択している関数の責務が大きくなっていないか確認してください。
変更はまだ行わず、改善案だけ出してください。
```

```text
VS Code上で出ている診断エラーを確認し、原因を整理してください。
修正する場合は最小限にしてください。
```

## 差分確認を必ず行う

Claude Codeがコードを変更したら、VS Codeのdiffビューで差分を確認します。

確認する観点は次のとおりです。

- 依頼した範囲だけが変わっているか
- 不要なリファクタリングが入っていないか
- 既存の命名や設計に合っているか
- テストや型チェックが必要か
- セキュリティや権限まわりに影響がないか

AIが作業した変更は、必ず人間がレビューしてからコミットします。

## よくあるトラブル

VS Code連携が動かない場合は、次を確認します。

- VS Codeの統合ターミナルから`claude`を実行しているか
- VS Codeで対象プロジェクトを開いているか
- `code`コマンドがPATHに入っているか
- VS Codeが拡張機能のインストールを許可しているか
- WSLを使っている場合、IDE検出やネットワーク設定に問題がないか
- `/config`でdiffツール設定が適切になっているか

## この章のまとめ

Claude CodeはCLIだけでも使えますが、VS Codeと連携すると、差分確認、選択範囲の共有、診断情報の共有がしやすくなります。

普段VS Codeで開発している場合は、VS Codeの統合ターミナルから`claude`を起動する使い方を基本にするとよいです。

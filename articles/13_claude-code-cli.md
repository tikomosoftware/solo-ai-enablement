# 13. Claude Code CLIの使い方

## この記事の目的

この記事では、Claude CodeをCLIで使う基本を説明します。

Claude Codeは、ターミナルで動くAIコーディングエージェントです。リポジトリを読み、ファイルを編集し、コマンドを実行し、作業を進めることができます。コードを書く道具というより、開発作業を一緒に進めるエージェントとして考えると理解しやすいです。

## Claude Codeでできること

Claude Codeは、次のような作業に使えます。

- コードベースの調査
- バグ修正
- 小さな機能追加
- テスト追加
- リファクタリングの提案
- ドキュメント作成
- エラー調査
- 実装方針の壁打ち
- コマンド実行と結果確認

Claude Codeはターミナル上で動きますが、単なるチャットではありません。必要に応じてファイルを読み、編集し、テストやビルドを実行するところまで進められます。

## 基本的な起動

プロジェクトのルートディレクトリでClaude Codeを起動します。

```text
claude
```

起動後は、自然文で依頼します。

```text
このリポジトリの構成を調べて、どこから読み始めればよいか教えてください。
```

```text
READMEを見て、開発環境のセットアップ手順に不足がないか確認してください。
```

```text
このテスト失敗の原因を調べて、最小限の修正を提案してください。
```

## 最初におすすめの依頼

いきなり大きな実装を任せるより、最初は調査や説明から始めるのがおすすめです。

```text
まずコードベースを調査してください。
変更はまだ行わず、主要なフォルダ、実行方法、テスト方法、注意点を整理してください。
```

```text
この機能を直したいです。
まず関連ファイルを探し、変更方針を説明してください。
実装はまだしないでください。
```

このように段階を分けると、Claude Codeがどこを見て何を考えているか確認しやすくなります。

## 実装を依頼するときのコツ

実装を依頼するときは、目的だけでなく制約も伝えます。

```text
ログイン画面のエラーメッセージを改善してください。
条件:
- 既存のAPI仕様は変えない
- レイアウトは大きく変えない
- 既存の文体に合わせる
- 変更後に関連テストを実行する
```

よい依頼に含めたい要素は次のとおりです。

- 何を達成したいか
- 変更してよい範囲
- 変更してはいけない範囲
- 守るべき設計やルール
- 実行してほしい確認コマンド
- 完了時に報告してほしい内容

## コマンド実行と権限

Claude Codeはコマンドを実行できます。便利ですが、注意も必要です。

特に次の操作は慎重に扱います。

- ファイル削除
- Gitの履歴変更
- `git reset`
- `git clean`
- force push
- データベース削除やリセット
- 本番環境に影響するコマンド

AIに依頼するときは、危険な操作を勝手に行わないように明示します。

```text
削除、reset、clean、force push、本番環境への操作は行わないでください。
必要な場合は、実行前に理由と影響を説明してください。
```

## 使いどころ

Claude Code CLIは、次のような場面で特に使いやすいです。

- コードベース全体を見ながら作業したい
- 複数ファイルにまたがる修正をしたい
- テストやビルドまで含めて進めたい
- 作業ログを会話として残したい
- VS Code以外のエディタでも同じように使いたい

## 注意点

Claude Codeに限らず、AIコーディングエージェントを使うときは次を守ります。

- 変更差分を必ず確認する
- テストやビルドを実行する
- 生成コードの意味を理解する
- 機密情報や認証情報を入力しない
- 大きな変更は小さく分ける
- 重要な判断は人間が行う

## この章のまとめ

Claude Code CLIは、ターミナルで使う開発支援エージェントです。

調査、実装、テスト、ドキュメント作成まで幅広く使えます。最初は「調査だけ」「方針だけ」のように段階を分け、慣れてから実装を任せると安全です。

# 第4回サンプル: 実プロジェクト導入の最初の一歩

## このプロジェクトについて

架空の社内FAQ検索ページです。

第4回では、実プロジェクトへAI利用を広げる前に、プロジェクト固有のルールを読み、最初に試す小さな改善を選ぶ流れを扱います。

## 今回の修正候補

FAQの検索対象が質問文だけになっています。

回答文にも検索語が含まれる場合、検索結果に出るようにします。

## 動作確認

`index.html` をブラウザで開き、検索欄に `パスワード` や `管理者` と入力して確認できます。

## ファイル

- `PROJECT-RULES.md`: このサンプルプロジェクト固有のルール
- `index.html`: FAQ検索画面
- `styles.css`: 見た目
- `app.js`: FAQデータと検索ロジック
- `DEMO-STEPS.md`: 登壇者用の実演手順

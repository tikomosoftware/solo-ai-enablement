# 第4回 実プロジェクトへ広げる

このディレクトリは、Claude Codeの使い方をサンプルから実プロジェクトへ広げる第4回以降の資料をまとめる場所です。

ここでは、個別プロジェクトの事情に合わせて、ルール、プロンプト、チェックリスト、FAQを育てていく流れを扱います。

## この回で扱うこと

- 実プロジェクトごとの前提確認
- プロジェクト固有のルールや禁止事項の整理
- よく使う依頼文のテンプレート化
- FAQやつまずき集の更新
- チーム内の共有会やふりかえりの進め方

## 扱わないこと

- 全社一斉導入
- すべての作業をAI前提に置き換えること
- 監査やセキュリティルールを省略した運用

## 参加者に事前にお願いすること

- 自分のプロジェクトでAIに手伝ってほしい作業を1つ考えておく
- プロジェクト固有の注意点や触ってはいけない領域を洗い出す
- 既存のレビュー、テスト、リリース手順を確認しておく

## 想定する成果物

- プロジェクト導入プロフィール
- プロジェクト別のAI利用メモ
- よく使うプロンプト集
- `article/`: 公開記事ドラフトや作業ログ

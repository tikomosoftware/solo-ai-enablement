# 第3回 チームで使うための運用にする

このディレクトリは、Claude Codeをチームで使うための運用ルールを整理する第3回セッションの資料をまとめる場所です。

第2回で小さな修正を試したあとに出てきたつまずきやヒヤリハットをもとに、チームとしての相談先、承認ルール、共有方法を整えます。

## この回で扱うこと

- やってよいこと、避けたいことの整理
- 承認が必要な操作の確認
- レビューや差分確認の流れ
- 困ったときの相談先
- ヒヤリハットや便利だった使い方の共有方法

## 扱わないこと

- 会社全体の正式ルール化
- 全プロジェクト共通の細かい禁止事項の確定
- 大規模な権限設計

## 参加者に事前にお願いすること

- 第1回・第2回で試してみて、困ったことを1つメモしておく
- 便利だった依頼文や、危なそうだと感じた提案があれば共有する
- 自分のチームでは誰に相談するのが自然か考えておく

## 想定する成果物

- チーム向けの簡易運用メモ
- FAQに追加する項目
- ヒヤリハット共有テンプレートの見直し
- `article/`: 公開記事ドラフトや作業ログ

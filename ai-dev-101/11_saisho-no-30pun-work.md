# 11. AI初心者向け 最初の30分ワーク

## この記事の目的

この記事は、AIをまだ仕事で使ったことがない人が、最初の30分でAIに触ってみるためのワークです。

細かい理屈をすべて読む前に、まず「AIに頼む」「返ってきた内容を直す」「そのまま信じない」を体験します。

このワークでは、機密情報、顧客情報、個人情報、社内だけの情報は使いません。ダミーの内容で試します。

## この30分でできればよいこと

- AIに短い依頼を出せる
- 返ってきた内容に追加依頼を出せる
- AIの出力をそのまま使わず、人間が直す感覚を持てる
- 入力してよい情報か迷ったら止まれる

## 使う前の確認

始める前に、次を確認します。

- 仕事で使ってよいAIツールか
- 個人アカウントや無料版に業務情報を入れていないか
- 顧客名、個人名、契約内容、売上、認証情報を入れないか
- 今日のワークではダミー情報だけを使うか

迷った場合は、実データを使わず、例文や架空の内容で試してください。

## 0分から5分: まず聞いてみる

最初は、仕事に近いけれど機密を含まない内容で試します。

そのまま入力する例:

```text
AIを仕事で使い始める人向けに、最初に気をつけることを5つ教えてください。
専門用語は少なめにしてください。
```

見るポイント:

- 分かりやすいか
- 一般論になりすぎていないか
- 自分の職場でそのまま言ってよい内容か

ここでは、AIの答えを正解として受け取るのではなく、たたき台として眺めます。

## 5分から10分: 追加で直してもらう

次に、返ってきた内容へ追加依頼をします。

入力する例:

```text
もう少し初心者向けにしてください。
不安をあおる表現は避けて、今日から小さく試せる言い方にしてください。
```

追加依頼の例:

```text
箇条書きを3つに減らしてください。
```

```text
チーム内チャットに投稿できる文面にしてください。
```

```text
注意点と、まず試してよいことを分けてください。
```

AIは1回で完成させる道具ではありません。会話しながら、使える形に近づけます。

## 10分から20分: 小さな仕事に使ってみる

次は、架空の予定変更をチャット文にします。

入力する例:

```text
以下の内容を、チーム内チャットに投稿する丁寧な文面にしてください。

内容:
- 明日の定例会の開始時間を変更する
- 変更前: 10:00
- 変更後: 11:00
- 理由: 先方都合
- 対象: プロジェクトメンバー

条件:
- 短くする
- 申し訳なさを出しすぎない
- 確認してほしいことを最後に入れる
```

返ってきたら、次を確認します。

- 時刻が間違っていないか
- 余計な事情を作っていないか
- 相手に失礼な表現がないか
- 自分たちの言い方として自然か

そのあと、必要ならこう頼みます。

```text
少しだけくだけた社内向けの表現にしてください。
ただし、失礼にはならないようにしてください。
```

## 20分から25分: 批判的に見てもらう

AIには、作るだけでなく確認も頼めます。

入力する例:

```text
以下のチャット文について、初めて読む人が誤解しそうな点、冷たく見える点、足りない情報があれば指摘してください。

[ここに作ったチャット文を貼る]
```

見るポイント:

- AIが出した指摘は本当に必要か
- 細かすぎる指摘はないか
- 自分の職場では不要な指摘ではないか

AIの指摘も候補です。全部直す必要はありません。

## 25分から30分: 振り返る

最後に、次の3つをメモします。

- 便利だったこと
- 不安だったこと
- 次に試したい小さい作業

チームで共有する場合は、次の形にすると簡単です。

```text
今日AIで試したこと:

便利だったこと:

そのまま使わず直したこと:

次に試したいこと:

入力情報で迷ったこと:
```

## 最初に試しやすい作業

次のような作業は、AI初心者でも試しやすいです。

- 社内チャット文の下書き
- 会議メモの整理
- 長い文章の要約
- 説明文の言い換え
- 手順書のたたき台
- アイデア出し
- FAQの候補作成

ただし、元の文章に機密情報や個人情報が含まれる場合は、利用ルールを確認してから扱います。

## このワークで扱わないこと

このワークでは、次は扱いません。

- 顧客情報や個人情報を使った相談
- 契約、法務、人事、会計などの重要判断
- ソースコードや本番ログの投入
- AIの回答をそのまま外部に提出すること
- AIエージェントによるファイル編集やコマンド実行

## この章のまとめ

最初の30分では、AIを完璧に使いこなす必要はありません。

大事なのは、AIに小さく頼み、返ってきた内容を人間が確認し、必要なら追加で直してもらう感覚を持つことです。

AI啓蒙記事ドラフト

AIをこれから使い始める人向けに、AIをまだ使っていない人でも読み進められるようにした記事群のたたき台です。

最初から完成形を目指すより、まずは共通認識を作るための文章として公開し、実践例や利用ルールが固まったところから追記していく想定です。

このフォルダは、AI活用の基礎を説明する独立した資料セットです。別フォルダの資料を読んでいることは前提にしません。

対象者

  • AIを仕事で使い始める人
  • AIチャットやAI支援ツールにまだ慣れていない人
  • 非エンジニアを含むチームメンバー

ゴール

  • AIにできること、苦手なことを理解する
  • AIに入力してよい情報、いけない情報を判断できる
  • AIの回答を人間が確認する前提で使える

扱わないこと

  • GitHub CopilotやClaude Codeの詳しい開発者向け操作
  • CLI、VS Code連携、安全設定などの開発環境の詳細
  • Hooks、MCP、サブエージェントなどの高度な自動化

目次

1. AIとは何か 2. なぜ今チームでAIを使うのか 3. AIにできること・苦手なこと 4. AIを使ってよいこと・いけないこと 5. 情報管理とセキュリティ 6. 実際の仕事での活用例 7. よい依頼の仕方、プロンプトの基本 8. 失敗例と注意点 9. チームで使うためのルール 10. 実践記事インデックス

開発作業でGitHub CopilotやClaude Codeを使う場合は、開発者向け資料を参照してください。

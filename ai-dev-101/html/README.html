AI活用入門資料

AIをこれから使い始める人向けに、AIをまだ使っていない人でも読み進められるようにした資料セットです。

チームでAIを使う前に押さえておきたい共通認識、基本的な使い方、注意点をまとめています。

このフォルダは、AI活用の基礎を説明する独立した資料セットです。別フォルダの資料を読んでいることは前提にしません。

対象者

  • AIを仕事で使い始める人
  • AIチャットやAI支援ツールにまだ慣れていない人
  • 非エンジニアを含むチームメンバー

ゴール

  • AIにできること、苦手なことを理解する
  • AIに入力してよい情報、いけない情報を判断できる
  • AIの回答を人間が確認する前提で使える

忙しい初心者向けの最短ルート

時間が限られている説明会や、AIをほとんど触ったことがない人には、まず次の3つだけを使います。

  • AI初心者向け 最初の30分ワーク
  • 初心者向け1枚チートシート
  • 入力してよい/ダメ判断クイズ

この3つで、「小さく頼む」「そのまま信じない」「迷った情報は入れない」という最初の感覚をそろえます。

Before / After形式の実例集は別資料としてまとめるため、このフォルダでは入口と基本の考え方を扱います。

扱わないこと

  • GitHub CopilotやClaude Codeの詳しい開発者向け操作
  • CLI、VS Code連携、安全設定などの開発環境の詳細
  • Hooks、MCP、サブエージェントなどの高度な自動化

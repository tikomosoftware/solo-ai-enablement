07. よい依頼の仕方、プロンプトの基本

この記事の目的

この記事では、AIにうまく依頼するための基本を説明します。

AIへの指示文は「プロンプト」と呼ばれます。ただし、難しいテクニックとして考える必要はありません。仕事で人に依頼するときと同じように、目的、背景、条件、期待する形を伝えることが大切です。

よいプロンプトは依頼が具体的

AIにうまく答えてもらうには、何をしてほしいのかを具体的に伝えます。

悪い例:

いい感じにまとめて

よい例:

以下の会議メモを、社内共有用に整理してください。
出力は「決定事項」「TODO」「未決事項」の3つに分けてください。
TODOには担当者と期限の欄を作ってください。

後者のほうが、AIは何をすればよいか判断しやすくなります。

伝えるとよい要素

プロンプトには、次の要素を入れると精度が上がります。

  • 目的: 何のために使うのか
  • 背景: どんな状況なのか
  • 対象読者: 誰に向けた文章なのか
  • 条件: 守ってほしい制約は何か
  • 出力形式: 箇条書き、表、文章、メール文など
  • トーン: 丁寧、簡潔、やわらかい、ビジネス向けなど
  • 確認したい観点: 誤字、抜け漏れ、リスク、わかりやすさなど

すべてを毎回入れる必要はありません。必要な情報を足すほど、期待に近い答えが返りやすくなります。

使いやすい型

次の型を覚えておくと、いろいろな場面で使えます。

目的:
背景:
依頼内容:
条件:
出力形式:
対象読者:

例:

目的: 社内メンバーにAI活用の基本を説明したい
背景: AIをまだ使ったことがない人もいる
依頼内容: 記事の導入文を作ってください
条件: 不安をあおらず、前向きな内容にする
出力形式: 600文字程度の本文
対象読者: プロジェクトメンバー

一回で完成させようとしない

AIへの依頼は、一回で完璧な答えを出すものではありません。

最初の回答を見て、追加で依頼します。

もう少し短くしてください。
初心者向けに言い換えてください。
具体例を3つ追加してください。
社外向けではなく、社内向けの表現にしてください。

このように会話しながら調整するほうが、よい結果になりやすいです。

AIに確認させる

AIは作るだけでなく、確認にも使えます。

以下の文章に、わかりにくい点、誤解されそうな点、抜け漏れがあれば指摘してください。
この手順書を初めて読む人がつまずきそうな箇所を挙げてください。
このメール文が冷たく見えないか確認してください。

自分で書いたものをAIに見てもらうと、別の視点を得られます。

この章のまとめ

AIにうまく依頼するコツは、特別な呪文を書くことではありません。

目的、背景、条件、出力形式、対象読者を伝えることです。

まずは「人に依頼するときに伝える情報を、AIにも伝える」と考えると始めやすくなります。

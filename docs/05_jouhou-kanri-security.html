05. 情報管理とセキュリティ

この記事の目的

この記事では、AIを仕事で使うときに特に重要な情報管理とセキュリティについて整理します。

AI活用で最も注意したいリスクのひとつは、入力してはいけない情報を外部サービスに入れてしまうことです。便利さより先に、守るべき情報の扱いを確認します。

AIに入力する情報は慎重に扱う

AIに入力した文章、資料、コード、ログなどは、利用するサービスや契約内容によって扱いが異なります。

所属組織として許可されたAI環境であれば、仕事で利用できる範囲が広がる場合もあります。一方で、個人アカウントや無料版の外部AIサービスでは、仕事上の情報を入力してはいけないケースが多くあります。

大事なのは、「AIに入れる情報は、外部に渡す可能性がある情報として扱う」ことです。

入力してはいけない情報の例

利用ルールがまだ明確でない場合、次の情報は原則として入力しないようにします。

  • 顧客名、担当者名、連絡先などの顧客情報
  • 氏名、住所、メールアドレス、電話番号などの個人情報
  • 契約書、見積書、請求書などの取引情報
  • 売上、利益、予算、原価などの未公開情報
  • 組織内の人事情報、評価情報、給与情報
  • 未公開の企画、戦略、ロードマップ
  • 認証情報、APIキー、パスワード、トークン
  • セキュリティ設定、脆弱性情報、アクセスログ
  • 公開されていないソースコードや設計資料

これらの情報をAIに入力したい場合は、必ず利用ルールや責任者に確認します。

入力しても比較的安全な情報

次のような情報は、比較的扱いやすいものです。

  • 一般的な仕事の進め方に関する相談
  • 機密を含まない文章の言い換え
  • 公開済み情報の要約
  • ダミーデータを使った例文作成
  • 個人や所属組織を特定できない抽象化された相談
  • 一般的なExcel関数、SQL、プログラミングの質問

ただし、「安全そうに見える情報」でも、組み合わせると機密になる場合があります。迷ったら具体情報をぼかす、ダミーに置き換える、入力しない、のいずれかを選びます。

匿名化とダミーデータの使い方

AIを使うときは、実名や実データを入れずに相談できることがあります。

たとえば、次のように置き換えます。

  • 顧客名を「A社」にする
  • 担当者名を「担当者X」にする
  • 実際の金額を「100万円程度」のような概算にする
  • 契約内容を抽象化する
  • 個人情報を削除する

ただし、匿名化しても文脈から特定できる場合があります。特定の顧客、案件、人物がわかる情報は慎重に扱います。

AIの出力にも注意する

AIに入力する情報だけでなく、AIが出した内容にも注意が必要です。

AIは、実在しない情報を作ることがあります。また、誤った説明、古い情報、偏った表現を含むことがあります。

外部に出す前には、次の点を確認します。

  • 事実は正しいか
  • 数字や日付に誤りはないか
  • 利用ルールに反していないか
  • 顧客や個人を不必要に特定していないか
  • 差別的、攻撃的、不適切な表現がないか
  • 出典が必要な情報に根拠があるか

この章のまとめ

AI活用では、入力する情報の管理が非常に重要です。

特に、顧客情報、個人情報、契約情報、認証情報、未公開情報は、原則として許可なくAIに入力しないようにします。

AIを安全に使う基本は、「具体情報を入れすぎない」「迷ったら入力しない」「外部公開前に人間が確認する」です。
